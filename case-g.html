sano GA4 트래픽 획득 보고서(2026년 7월 1일~10월 19일)입니다. 보라 상자는 로그인 복귀, 빨간 상자는 개발 주소에서 생긴 세션입니다.

브랜드

sano, 광고 운영 AI 에이전트(개인 프로젝트)

맡은 일

GA4 이벤트 설계, 데이터 진단과 수정

기간

2026.07 — 현재

도구

GA4, 메타 픽셀과 서버 전환, 자체 DB

GA4 진단

GA4에서 잘못 집계된 유입을 찾아 측정 방식을 다시 설계했습니다.

상황

직접 만든 광고 운영 AI 에이전트 sano를 메타 광고로 알리며 사전 신청과 가입을 받았습니다. 그런데 GA4, 메타 픽셀, 실제 가입 기록의 숫자가 서로 맞지 않았습니다.

한 일

숫자가 어긋나는 원인 네 가지를 찾아 측정 방식을 수정했습니다. 랜딩 조회부터 사전 신청, 가입, 매체 연결, 결제 시작까지 이벤트를 새로 설계하고, 실제 방문과 행동을 구분해 볼 수 있도록 했습니다.

결과

GA4가 메타보다 많이 집계한 광고 유입

데이터센터 트래픽이 섞인 탓

새로 설계한 GA4 이벤트

13종

맞춤 측정기준 7개 등록

* 2026년 7월 1일부터 10월 19일까지 sano GA4 속성과 2026년 10월 작업 기록 기준입니다.

찾은 원인과 고친 방법

  • 구글 로그인 복귀

    구글 로그인 후 돌아온 방문이 accounts.google.com 추천 유입으로 바뀌었습니다. GA4의 원치 않는 추천 목록에 로그인과 결제 도메인을 추가하고, 가입자의 첫 유입 경로를 DB에 따로 기록했습니다.

  • 데이터센터 트래픽

    최근 7일 활성 사용자의 절반이 데이터센터가 있는 도시에서 집계됐고, GA4의 광고 유입은 메타의 1.8배였습니다. 화면이 실제로 보였을 때만 기록하는 랜딩 이벤트를 새로 설계했습니다.

  • 개발 주소 방문 혼입

    배포 미리보기 주소와 로컬 개발 주소의 방문이 GA4에 섞였습니다. 추적 도구가 실제 서비스 주소에서만 작동하도록 수정했습니다.

  • 픽셀 가입 누락

    실제 가입 3건 중 메타 픽셀에 기록된 가입은 0건이었습니다. 서버 전환(CAPI)을 연동하고 브라우저와 서버에서 같은 이벤트 ID를 사용해 중복 제거까지 확인했습니다.

설계한 이벤트

  1. 랜딩 조회
  2. 섹션 도달
  3. 버튼 클릭
  4. 사전 신청
  5. 로그인 시작
  6. 가입
  7. 매체 연결
  8. 결제 시작

  • 고친 뒤 처음 본 숫자

    사람 방문을 기준으로 측정한 첫날인 10월 12일, 랜딩을 본 29명 중 버튼을 누른 사람은 1명이었습니다.

이시스에서는

이시스코스메틱 자사몰에서도 카카오싱크 가입, 구매, 리필 재구매를 이벤트로 설계하겠습니다. 카카오 로그인 후에도 최초 유입 경로가 유지되는지 확인하겠습니다.
