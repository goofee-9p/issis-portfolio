지누스가 29CM 라이브 기간에 보낸 카카오톡 채널 메시지입니다.

맡은 일

메시지 기획과 결과 비교

기간

2026

메시지 테스트

GA4 데이터로 발송 시간과 랜딩 페이지를 분석합니다.

상황

담당 브랜드의 카카오톡 채널 메시지는 발송 대상, 시점, 혜택을 유지하고 메시지 유형만 바꿔 약 50회 발송했습니다. 별도로 발송 시간과 랜딩 페이지를 정하는 방법도 검토했습니다.

한 일

제가 만든 sano 웹사이트의 28일간 GA4 데이터로 시간대별 활성 사용자와 메인 페이지 이후 이동 경로를 분석했습니다. 이를 바탕으로 12시와 19시 발송을 비교하고, 메시지별 목적에 맞는 페이지로 바로 연결하는 방안을 세웠습니다. 실제 발송에 적용하기 전 검증할 가설로 두었습니다.

발송 시간과 랜딩 페이지 정하기

카카오 메시지의 발송 시간과 랜딩 페이지를 정하기 위해, 제가 만든 sano 웹사이트의 GA4 데이터로 두 가지 분석을 해 봤습니다. 이시스에서는 실제 자사몰 데이터를 확인하고 같은 방법을 적용해 보겠습니다.

발송 시간

GA4에서 날짜와 시간별 활성 사용자를 확인했습니다. 해외 사용자 282명(47.7%)을 제외한 뒤 시간대별 활동을 비교하니 12~15시에 집계가 집중됐고, 19시에도 활동이 확인됐습니다. 오후 9시부터 다음 날 오전 8시까지는 광고성 메시지 발송에 별도 사전 동의가 필요해 후보에서 제외했습니다. 이를 바탕으로 12시와 19시 발송을 A/B 테스트하는 안을 세웠습니다.

랜딩 페이지

경로 탐색으로 메인 페이지 다음에 조회한 페이지를 확인했습니다. 메인 페이지 조회 352회 중 다른 페이지 조회로 이어진 경우는 101회(28.7%)였고, 메인 방문 세션의 참여율은 43.2%로 전체 평균 44.9%보다 낮았습니다. 이를 바탕으로 메시지마다 목적에 맞는 페이지로 바로 연결하고, UTM과 전환 데이터를 함께 확인해 참여율과 구매 전환을 비교하는 안을 세웠습니다.

다른 메시지 운영 사례

  • CRM 메일, 개인 프로젝트

    사전등록자에게 보내는 메일을 직접 기획하고 발송했습니다. 수신동의 여부에 따라 정보성 메일과 광고성 메일의 발송 대상을 구분하고, 광고 표시와 수신거부 기능이 반드시 적용되도록 코드를 작성했습니다. 1인당 하나씩 사용할 수 있는 이용권 코드를 발급하고, 메일 열람률 대신 이용권 등록 여부를 성과 기준으로 삼았습니다.
